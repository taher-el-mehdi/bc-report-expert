# Report Designer toolbox icons

PNG icons extracted from the local Microsoft RDLC Report Designer VSIX reference package
(`Microsoft.ReportDesigner.Controls.dll` embedded `Microsoft.ReportDesigner.images.*` bitmaps)
for Visual Studio–style toolbox chrome. They are design-time UI assets only; the designer
runtime does not load Microsoft designer assemblies.

| File | Toolbox item |
|------|----------------|
| `TextBox.png` | TextBox |
| `Rectangle.png` | Rectangle |
| `Line.png` | Line |
| `Image.png` | Image |
| `Table.png` / `Matrix.png` / `List.png` | Tablix variants |
| `Chart.png` | Chart |
| `Subreport.png` | Subreport |
| `Gauge.png` | Gauge |
| `Pointer.png` | Pointer / select tool |
